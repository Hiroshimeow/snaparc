# SnapArc product asset provenance checkpoint

This checkpoint records what can be established from the local legacy Git
history. It is not a substitute for a rights-holder attestation.

## Retained assets

- `src/animate/`: 164 PNG tray-animation frames.
- `src/icons/`: 8 application/action icons, including translate, summarize,
  capture, pause and voice-state assets.

## Legacy repository evidence

The assets already existed in the private predecessor repository before the
clean SnapArc Git history was created. Legacy history shows animation/icon
changes in commits dated 2026-01-21, 2026-10-21 and 2026-10-22. Icon-specific
updates also appear on 2026-04-03 under the maintainer name recorded by Git.

No tracked documentation was found that attributes these files to an external
icon pack, stock site, artist, font set or image URL. Absence of attribution is
not proof of ownership.

## Release rule

The final GitHub approval package requires the maintainer to attest that the
retained assets may be published. If that attestation cannot be made for a
specific asset, that asset must be removed or replaced before the public push.

Runtime/user media such as screenshots, clipboard captures and recordings are
not product assets and are categorically excluded by the release asset audit.
